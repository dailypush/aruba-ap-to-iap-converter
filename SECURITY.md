# Security Policy

## Reporting Issues

Please do not publish security-sensitive details in a public issue. Open a
private report through GitHub security advisories if available, or contact the
repository maintainer directly.

## Scope

Security-sensitive areas include:

- Privileged macOS setup helpers
- Direct-connect DHCP helper behavior
- Serial/APBoot command sequencing
- File handling for firmware and logs

Firmware images are not bundled with this project.
